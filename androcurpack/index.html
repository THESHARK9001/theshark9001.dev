DOWNLOAD AndroCurPack for Windows

Requirements Windows:

7-zip or WinRAR


Instructions for installing on Windows:

1. Using 7-zip or WinRAR, extract "androcurpack_windows.7z"

2. Open the "androcurpack_windows" folder

3. Run "install.bat"

4. Click "Yes" when the UserAuth window pops up

5. When the next window pops up, under "Scheme" select "androcurpack"

6. Click "Apply"



DOWNLOAD AndroCurPack for Linux

ONLY TESTED ON ARCH WITH KDE PLASMA DE USING WAYLAND


Requirements for Linux:

7-zip (sudo pacman -S 7zip)


Instructions for installing on Linux:

1. Extract androcurpack_linux_kde_plasma.7z (7z x androcurpack_linux_kde_plasma.7z)

2. Run the androcurpack.sh bash script (androcurpack.sh)

3. Press the Win key and type "Pointer" then open up the setting called "Pointer"

4. Change to AndroCurPack

5. Click "Apply"
